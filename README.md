# TCToolbox

台服自製的整合工具插件，收錄大量獨立小功能模組，每個模組各自開關、預設全部關閉。開啟主視窗後依分頁分類瀏覽與設定。

## 指令

- `/tctoolbox`：開啟主視窗
- `/tcstop`：停止目前正在進行的導航／自動化（多個模組共用）
- `/tcicons`：圖示對照表（開發輔助）
- `/tcspeed`：切換移動速度倍率模組
- `/tcduty`、`/tcdf`：把任務搜尋器開到指定副本
- `/tpflag`：傳送到離地圖旗標最近的乙太之光（需要 Lifestream）
- `/gotoflag`：走到旗標位置（需要 vnavmesh）
- `/tcnext`、`/tcprev`、`/tcswitch`：AutoRetainer 角色切換

## 背包・裝備

- **自動物品頁面轉移**：按住指定鍵右鍵點物品，直接搬去對應頁面（背包⇄雇員、背包⇄公會置物櫃、背包⇄陸行鳥鞍袋、兵裝庫→背包）
- **自動取出全部魔晶石**：手動取出裝備上一顆魔晶石後，自動接續取完同一件裝備上剩下的
- **自動精製魔晶石**：一鍵把背包與兵裝庫裡精鍊度已滿的裝備逐件精製
- **背包堆疊合併**：手動按鈕，把同一款道具的零散堆疊併成滿堆（僅背包第 1～4 頁）
- **商店快速購買（預設）**：記住「開哪個商店、點第幾項」，之後一鍵重播叫出購買對話框
- **收藏櫃：可收納裝備一鍵存入**：一鍵把背包與兵裝庫裡可收納的裝備存入收藏櫃，染色／投影／精鍊等會自動跳過
- **補上「複製道具名」**：在背包、雇員背包、陸行鳥鞍囊、裝備欄、投影台、商店等右鍵選單補上此項目
- **貨幣上限警示**：神典石、票據等貨幣接近上限時在伺服器資訊列警示
- **道具丟棄清單**：維護一份想丟棄的道具清單，逐件或整批發起丟棄
- **雇員存取加速（同款全部）**：同時開著背包與雇員背包時，右鍵補上「同款一次全部寄放／取回」
- **投影台：收藏櫃可收納裝備取出**：把投影台裡可收進收藏櫃的裝備取回背包
- **投影台：重複幻影取出**：掃描投影台，取回同一件裝備多出的份數
- **投影台：整套幻影取出**：依套裝幻影化組合，把湊得齊全的幻影一次取回背包
- **投影台：攔截重複收納**：對已在投影台裡的外觀再次幻影化時攔下確認框並說明原因
- **道具右鍵開灰機 wiki**：右鍵選單加上「在灰機 wiki 查看」，直接開啟該道具的頁面
- **信箱一鍵收取**：信箱開著時一鍵依序收下所有信件的附件與 Gil
- **兵裝庫：非套裝裝備取回背包**：把兵裝庫裡未被任何套裝使用的裝備搬回背包
- **箱類「全部開啟」**：可整疊開啟的箱子右鍵補上「全部開啟」
- **公會置物櫃預設頁面**：開啟公會置物櫃時自動切到指定頁面（第 1～5 頁或水晶頁）
- **報酬界面最佳化**：報酬視窗上方新增依職業分類的一鍵領取按鈕，並省略逐件確認框
- **道具快速拆分**：可疊道具右鍵補上「快速拆分」，輸入數字即拆
- **一鍵全修（跨容器）**：修理視窗新增按鈕，一次修完裝備中裝備與下拉選單裡的每個容器
- **批次僱員改名**：半自動流程（幻想藥→傳喚→卸裝→手動改名→穿回裝備→送回），並附「收回所有已完成探險」按鈕
- **陸行鳥鞍囊：寄放重複道具**：把背包裡鞍囊已有同款的道具整堆放進鞍囊
- **商店介面預設值**：開啟軍票商店時自動切到指定分頁
- **商店列表顯示真實道具圖示**：商店、兌換所、軍票交換、收藏品交易等清單縮圖改為真實道具圖示
- **收藏品一鍵全交**：收藏品交易視窗開著時連續按交易鈕，把目前分頁收藏品全部交完
- **幻卡回收清單**：列出背包裡九宮幻卡列表已收錄（故為多餘）的卡片與可回收金碟幣

## 戰鬥・小隊

- **自動維持食物 buff**：在指定時機（進副本／倒數開始／戰鬥狀態變更）自動補上設定的食物
- **系列賽獎勵一鍵領取**：星里路標報酬視窗新增按鈕，一次領完當季所有系列賽獎勵
- **招募詳細視窗自動加入**：開啟招募詳細內容後自動按下「加入」（可設延遲、取消鍵）
- **自動最優隊員推薦**：副本完成時自動給予最優隊員推薦，優先同職業、其次同職能
- **自動恢復焦點目標**：副本內焦點目標消失（王離場再出現、重新生成等）時自動重新設回
- **自動刷新招募板**：招募視窗開著時每隔一段時間（預設 30 秒）自動更新
- **自動選中目標**：沒有選中目標時自動選最近的敵人，可另外開啟稀有 FATE 敵優先切換
- **共鬥 F.A.T.E. 進度總覽**：彙整各資料片共鬥 FATE 完成數與寶石庫存的唯讀視窗，附手動地圖／傳送
- **招募清單排序**：把可加入的招募排到清單最上面
- **指令開啟任務搜尋器**：`/tcduty` 直接把任務搜尋器開到指定副本並選取
- **F.A.T.E. 自動等級同步**：進入等級上限低於自己的 FATE 時自動開啟等級同步
- **F.A.T.E. 總覽與導航**：唯讀列出本區 FATE 的名稱、等級、進度、剩餘時間與距離，附導航按鈕（需要 vnavmesh）
- **副本開始／結束播報**：副本開始與通關時各發送一句自訂訊息
- **任務搜尋器快速登記**：一鍵把搜尋器開到目前選取或收藏的常用副本
- **小隊列表顯示目標標記**：把場上目標標記同步顯示在小隊列表對應隊員名字前
- **移動速度倍率（限白名單副本）**：在指定副本內套用移動速度倍率，預設關閉、白名單預設為空
- **招募視窗不自動關**：查看招募詳情時有人加入／離開，改為刷新視窗而非關閉
- **任務搜索器設置最佳化**：搜索器視窗新增各項設定的圖示按鈕（中途參戰、解除限制、等級同步等）
- **敵對列表界面最佳化**：每列外側顯示體力數值／百分比與詠唱剩餘秒數
- **目標情報界面最佳化**：目標情報顯示實際體力數值（可用萬／億簡寫）、百分比、詠唱剩餘秒數
- **招募板單頁筆數**：把招募板單頁筆數從預設 50 筆改為自訂值（上限 100）
- **招募清單過濾器**：隱藏重複洗版、關鍵字黑白名單、高難度已滿職的招募
- **戰鬥中排隊傳送**：戰鬥中排隊一個乙太之光，戰鬥結束後透過 Lifestream 自動傳送
- **招募說明可選取**：另開面板顯示可反白複製的招募說明文字，並把網址轉為可點連結
- **天書格子點擊直接開副本**：點擊天書格子直接開啟對應副本或輪盤的任務搜尋器
- **狩獵列車顯示到 Mappy**：把 Hunt Helper 的狩獵列車清單同步顯示到 Mappy 地圖標記

## 公會・生活

- **AutoRetainer 角色切換**：伺服器資訊列顯示目前是 AutoRetainer 清單裡第幾個角色，附 `/tcnext`、`/tcprev`、`/tcswitch`
- **自動使用生產／採集指南**：生產職／採集職未滿等且沒有加成 buff 時自動使用工程學／生存學指南
- **自動確認老主顧交易結果**：老主顧交易完成的結果視窗自動確認關閉
- **合建素材一鍵全交**：公會工房「合建」素材交納視窗新增一鍵全交按鈕
- **自動園圃作業**：一鍵批次收穫／護理／施肥自家或公會庭院的地壟與花盆，可批次播種
- **自動餵食陸行鳥**：野外陸行鳥剩餘時間不足時自動餵食基沙爾野菜
- **自動繳交道具**：任務交付視窗開啟時自動填入並交出要求的道具（含優質道具確認）
- **老主顧交易總覽**：唯讀彙整各老主顧滿意度等級、進度與每週交易次數
- **軍票商店快速交換**：「軍隊物資交換」視窗開著時新增小面板，輸入道具名與數量即可交換

## 介面・雜項

- **成就進度追蹤**：加入想盯的成就，按下重新整理即向伺服器查詢目前進度
- **風脈泉一覽**：列出目前區域每個風脈泉與是否已共鳴，可標旗、插場地標記或導航
- **防自動掛機登出**：定期歸零遊戲閒置計時器，避免長時間未操作被登出
- **阻止標題動畫**：標題畫面與角色選擇畫面持續歸零閒置計時，阻止待機宣傳影片播放
- **自動切換輸入法配置**：文字輸入框取得／失去焦點時自動切換指定輸入法配置
- **自動重複點擊**：長按快捷欄按鍵時以設定間隔自動重複觸發
- **周邊玩家統計**：伺服器資訊列顯示周邊玩家數，可設偵測規則（名稱／狀態／公會標籤／距離）並通知執行指令
- **顯示主線任務進度**：冒險筆記標題列顯示目前資料片主線剩餘任務數與完成百分比
- **自動隱藏橫幅**：勾選要屏蔽的畫面橫幅（理符、FATE、尋寶等）連同音效一起攔掉
- **自動隱藏多餘彈窗**：勾選的系統彈窗（推薦任務、資訊中心、成就資訊等）出現即自動關閉
- **解除重登冷卻鎖**：持續解除角色選擇畫面的重登冷卻，登出後可立即重登（有帳號風險，預設關閉）
- **數字輸入框放大上限**：把上限卡在 99 的數字輸入框放寬到自訂上限
- **自動 QTE**：副本／劇情 QTE（連打、長按、按鈕）時自動連發完成
- **自動接受任務**：任務受理視窗出現後自動按下「接受」
- **旗標指令**：`/tpflag` 傳送到離旗標最近的乙太之光（需要 Lifestream）、`/gotoflag` 走到旗標位置（需要 vnavmesh）
- **圖示對照表**：開發輔助，畫出 DTR／SeString 可用圖示並可一鍵複製識別字
- **放大中文輸入候選字**：把遊戲內建輸入法候選字清單整塊放大
- **登入後執行指令**：登入完成後依序自動執行自訂的斜線指令
- **解除互動限制**：關閉視野外／被遮擋／距離過遠等客端互動限制檢查
- **聊天座標自動開地圖**：聊天訊息出現地圖座標連結時自動開地圖並插旗標
- **點擊移動**：按住修飾鍵點地面即自動走過去（需要 vnavmesh）
